Пока пусто. Ваши чаты сохраняются здесь, на этом компьютере.

О чём поработаем?

Выберите папку проекта и напишите задачу. Под капотом работает ваш Claude Code CLI, а история чатов хранится в Mark Desk.

MCP-серверы

MCP-серверы дают Claude дополнительные инструменты (файлы, базы, браузер, сервисы). Включённые серверы подключаются при следующем сообщении. Сервер типа stdio запускает программу на вашем компьютере — подключайте только то, чему доверяете. Токены хранятся открытым текстом в папке данных Mark Desk.
