# Mark Desk

Свой интерфейс (Electron) поверх Claude Code CLI, с собственной историей чатов.

## Запуск

```
npm install
npm start
```

Если после `npm install` нет `node_modules/electron/dist/electron.exe`, выполните `node node_modules/electron/install.js`.

## Как это работает

- `main.js` находит `claude` (из настроек, PATH, `~/.local/bin` или копию внутри десктопного приложения Claude)
  и запускает его как `claude -p --output-format stream-json --include-partial-messages`.
  Запрос передаётся через stdin.
- `renderer/` рисует поток событий: ответ по мере генерации, размышления, вызовы инструментов и их результат, стоимость и время.
- Вход выполняется прямо в окне (`claude auth login`): ссылка, поле для кода; пароли приложение не видит.
- Режимы прав: чтение, правки, план, без вопросов.

## MCP-серверы

Кнопка «🔌 MCP» в шапке открывает список серверов: включить/выключить, добавить (stdio, http, sse), изменить, удалить,
импортировать из JSON (формат `{"mcpServers": {...}}` из документации MCP).

- Список хранится в `%APPDATA%\Mark Desk\mcp.json` (токены — открытым текстом).
- При каждом сообщении включённые серверы передаются в CLI через `--mcp-config`, а их инструменты заранее разрешаются
  (`--allowedTools mcp__<имя>`), потому что в неинтерактивном режиме CLI не может спросить разрешение.
- Статус («подключён · N инстр.») берётся из события `init` последнего запуска.
- Галочка «Также использовать серверы из Claude CLI» управляет `--strict-mcp-config`.

### Вход в удалённые MCP-серверы (OAuth)

Для серверов http/sse в окне MCP есть кнопка «Войти (OAuth)» (например, Higgsfield: `https://mcp.higgsfield.ai/mcp`).
`oauth.js` сам проходит весь поток: обнаруживает сервер авторизации (RFC 9728/8414), регистрирует клиент (RFC 7591),
открывает браузер, принимает код на `http://127.0.0.1:<порт>/callback` (PKCE S256, проверка `state`) и обменивает его на токены.

- Токены хранятся в `%APPDATA%\Mark Desk\oauth.json`, зашифрованные средствами ОС (Electron `safeStorage`).
- Перед каждым запуском токен при необходимости обновляется (refresh token), а в CLI он передаётся заголовком
  `Authorization: Bearer …` только в временном конфиге запуска; в `mcp.json` токены не попадают.
- «Выйти» забывает токены; удаление сервера или смена его URL удаляет токены автоматически.
- Если задан свой заголовок `Authorization`, OAuth-токен не подставляется.

## Собственная история

- Каждый чат целиком сохраняется в `%APPDATA%\Mark Desk\history\<id>.json` (сообщения, размышления, вызовы инструментов, стоимость).
  Слева — список чатов; чат можно открыть, продолжить или удалить.
- Для продолжения беседы используется `--resume` (быстро, с кэшем CLI). Если сессии CLI уже нет или вы сменили папку,
  Mark Desk сам передаёт Claude сохранённую переписку, так что история не зависит от хранилища CLI.
- Сам CLI по-прежнему пишет свои сессии в `~/.claude`; Mark Desk их не читает и не удаляет.
